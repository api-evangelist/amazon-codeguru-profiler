Learn how to connect AWS DevOps Agent investigation events to third-party tools such as Jira using Amazon EventBridge and AWS Lambda. This post walks through a deployable AWS CDK solution that automatically creates and updates Jira issues as an investigation progresses, and shows how to adapt the same pattern to ServiceNow, PagerDuty, and other tools.
